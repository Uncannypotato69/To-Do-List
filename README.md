📝 Uncanny To-Do List
Welcome to the Uncanny To-Do List, a minimalistic and efficient task management app built with React! 🚀 This app helps you organize your day with ease, whether you're managing tasks for work, school, or personal projects.

🌟 Features
Add tasks with a click of a button.
Edit tasks directly by clicking on them.
Dynamic input fields that adjust width based on your text.
Customizable experience: sound and theme toggles to personalize your interface.
Accessible sound options for users with different needs.
💻 Live Demo
Check out the live demo here: Uncanny To-Do List 🌐

🛠️ Tech Stack
React for building the user interface.
use-sound for sound effects.
Custom Hooks for managing sound and theme state.
